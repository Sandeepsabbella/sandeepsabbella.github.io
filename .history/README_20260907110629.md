# sandeepsabbella.github.io

Personal portfolio website for Sandeep Sabbella.

## Structure

The site is a dependency-free static page. Open `index.html` in a browser to preview it.
Hash-based routing loads each top-level section as its own view, while nested categories
keep their URL (for example, `#ai-projects`) and open within their parent view.
The fixed floating dock provides quick access to the primary routes and GitHub.

- **Home** — introduction and current focus
- **Latest** — featured work and recent notes
- **Works** — AI, full-stack, open-source, research, and case study categories
- **Tools** — AI, productivity, developer, and learning resources
- **Tech Blog** — implementation, paper, podcast, engineering, and experiment categories
- **Resume** and **Contact**
- **Certifications** — rendered from [`cert-data.json`](./cert-data.json), including provider, skills,
  credentials, dates, and an optional verification URL

Replace the placeholder social links, email address, and `resume.pdf` with the final profile details before publishing.
